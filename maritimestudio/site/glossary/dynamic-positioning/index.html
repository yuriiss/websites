DP & Station-Keeping

Dynamic positioning terms explained: DP class, FMEA, ASOG, CAMO, capability plots, drive-off, drift-off, thruster allocation, position reference systems and more.

A

Annual DP TrialsDP
A yearly programme of tests that verifies a DP vessel's redundancy concept still performs as documented in its FMEA. Trials typically simulate worst-case failures — thruster loss, power section blackout, reference dropout — and confirm the vessel maintains position within its post-failure capability. Findings feed back into the FMEA and the vessel's DP operations manuals.
ASOG — Activity Specific Operating GuidelinesDP
A decision-support matrix that defines the operational, environmental and equipment limits for a specific DP activity, and the actions required as conditions move from normal (green) through advisory (blue/yellow) to emergency (red). The ASOG turns the vessel's FMEA and capability analysis into clear go/no-go criteria the bridge team can act on in real time.
Azimuth ThrusterDP
A propulsion unit that can rotate through 360 degrees, producing thrust in any horizontal direction without a conventional rudder. Azimuth thrusters give DP vessels the omnidirectional force needed for precise station keeping and are a key input to thruster allocation logic.

B

BlackoutDP
A total loss of electrical power on the main switchboard, leaving the vessel without propulsion and station-keeping ability. Preventing blackout — and proving that a single failure cannot cause one — is central to DP class 2 and 3 design, power management strategy and FMEA analysis. Blackout recovery time is a critical performance measure tested during trials.
Bow ThrusterOPERATIONS
A transverse propulsion unit mounted in a tunnel near the bow, used to push the fore end of the vessel sideways. Bow thrusters support berthing, low-speed manoeuvring and DP station keeping, where they typically provide the forward lateral force in the thruster allocation scheme.

C

CAMO — Critical Activity Mode of OperationDP
The vessel configuration — power plant, thrusters, control systems and reference systems — that delivers the highest practical level of redundancy for safety-critical DP activities. Operating in CAMO means a single failure should not exceed the worst-case failure design intent, keeping the vessel within its post-failure capability.
Capability PlotDP
A polar diagram showing the maximum environmental conditions (wind, current, waves) in which a DP vessel can hold position, plotted for every heading. Capability plots are produced for intact condition and for defined failure cases, and are used in operational planning to confirm adequate margin before starting work.
Closed Bus-Tie OperationDP
Running a DP vessel's power plant with the bus-tie breakers between switchboard sections closed, so all generators feed a common bus. Closed bus improves fuel efficiency and reduces running hours, but requires demonstrably fast, reliable protection systems so that a single fault cannot propagate across the whole plant — a major focus of modern FMEA and HIL testing.
Common-Mode FailureDP
A single event or hidden dependency that defeats supposedly independent redundant systems at the same time — for example contaminated fuel affecting all generators, or a shared cooling line serving both switchboard rooms. Hunting down common-mode failures is one of the primary objectives of a DP FMEA.
Consequence AnalysisDP
A continuous online function in the DP control system that predicts whether the vessel could still hold position and heading if the worst-case single failure occurred right now, given current weather and thruster loading. If the prediction fails, the system raises an alarm so the crew can reduce exposure before a failure actually happens. Required for DP class 2 and 3 vessels.

D

DGNSS — Differential GNSSDP
Satellite positioning enhanced by correction data from reference stations, improving accuracy from metres to decimetres. DGNSS is the workhorse position reference for most DP operations, usually operated in pairs from independent providers and cross-checked against a different reference technology such as hydroacoustics or laser.
DP Alert SystemDP
The standardised three-level status indication for DP operations: green (normal), yellow (degraded — prepare to suspend work), and red (emergency — terminate work and move to safe position). Alert levels are broadcast to relevant stations such as the drill floor, dive control or crane cab so everyone reacts consistently to a change in DP status.
DP Class (1, 2, 3)DP
The IMO equipment classes defining a DP vessel's tolerance to failure. DP 1 has no redundancy; DP 2 must withstand any single failure of an active component without losing position; DP 3 must additionally survive loss of an entire compartment to fire or flooding, with physically separated redundant systems. The required class is set by the consequence of losing position for the activity performed.
DP FootprintDP
The observed excursion pattern of a vessel about its setpoint while holding station — effectively a scatter plot of position error over time. Footprint plots recorded during trials and operations give a practical measure of station-keeping performance in the prevailing conditions.
DP IncidentDP
Any undesired event affecting DP integrity — from a single reference rejection to a full drive-off or drift-off. Industry schemes such as IMCA's station-keeping incident reporting collect and anonymise these events so lessons propagate across the fleet; investigating and learning from them is a recognised part of DP assurance.
DP — Dynamic PositioningDP
A computer-controlled system that automatically holds a vessel's position and heading using its own thrusters, based on continuous input from position reference systems, gyrocompasses, motion sensors and wind sensors. DP enables offshore drilling, diving, construction, cable lay and shuttle offloading without anchors, and is the core discipline behind Maritime.Studio's <a href="https://maritimestudio.no/services">consulting and training services</a>.
DPO — Dynamic Positioning OperatorDP
The certified officer who operates the DP system on the bridge, monitors position references, power and thrusters, and executes the ASOG when conditions change. DPO qualification follows a structured path of induction and simulator courses, logged seatime and assessment — most commonly under the Nautical Institute scheme.
Drift-OffDP
A loss of position in which the vessel is carried off station by wind, waves and current because it no longer has enough thrust — typically after power or thruster failures. Drift-off is the "passive" loss-of-position mode, in contrast to drive-off, and the post-failure capability analysis exists to predict and prevent it.
Drive-OffDP
A loss of position in which the DP system actively powers the vessel away from its setpoint — usually caused by a faulty position reference, sensor error or control system malfunction that the system acts upon. Drive-offs develop fast and are a key scenario in DPO emergency training and simulator drills.

E

Environmental EnvelopeDP
The combination of wind, wave and current limits within which a vessel can safely conduct a given DP operation, derived from capability plots and operational experience. Working inside the envelope preserves margin for the worst-case failure; the ASOG defines what to do as conditions approach its edge.
ERN — Environmental Regularity NumberDP
A DNV notation expressing, as a set of percentile figures, a vessel's ability to keep position in Norwegian continental shelf weather conditions under defined failure states. ERN offers a compact comparative measure of station-keeping robustness between vessels.

F

FMEA Proving TrialsDP
The practical sea trials that validate the FMEA's conclusions by deliberately injecting failures — tripping breakers, failing thrusters, disconnecting references — and observing whether the system responds as the analysis predicted. Discrepancies between predicted and observed behaviour are among the most valuable findings in DP verification.
FMEA — Failure Mode and Effects AnalysisDP
A systematic engineering study that examines every component of a DP vessel's power, propulsion and control systems, asks how each can fail, and traces the effect of each failure on station keeping. The FMEA defines the vessel's worst-case failure design intent and proves — on paper and then in proving trials — that no single failure exceeds it. It is the foundational document of DP assurance, and a core specialty of <a href="https://maritimestudio.no/services">Maritime.Studio's consulting practice</a>.

G

GNSS — Global Navigation Satellite SystemDP
The umbrella term for satellite constellations — GPS, GLONASS, Galileo and BeiDou — that provide worldwide positioning. In DP, raw GNSS is refined with differential corrections (DGNSS) and monitored closely, because satellite signal anomalies are a classic trigger for reference rejection or drive-off scenarios.
GyrocompassDP
A north-seeking compass that uses a fast-spinning rotor (or fibre-optic/ring-laser equivalent) to find true north independent of the Earth's magnetic field. DP vessels carry two or three gyrocompasses, since heading is as critical to station keeping as position — a heading error rotates every other measurement.

H

Hardware-in-the-Loop (HIL) TestingDP
Testing a real DP control system or power management system against a real-time simulation of the vessel, so that failure scenarios too risky or impractical to create on board — sensor freezes, network storms, protection race conditions — can be exercised systematically. HIL complements FMEA proving trials by covering software behaviour that hardware trials cannot safely reach.
Heading ControlDP
The DP function that automatically maintains the vessel's heading against environmental forces, usually while position is also controlled. Choosing the optimal heading — typically weathervaning into the dominant environment — minimises thruster load and preserves capability margin.
Hydroacoustic Position Reference (HPR)DP
A position reference that measures range and bearing to transponders deployed on the seabed using acoustic signals — in ultra-short, short or long baseline configurations. HPR is independent of satellites, making it a valuable complement to DGNSS, particularly for deepwater drilling and subsea construction.

I

Independent Joystick SystemDP
A back-up manual control system, separate from the main DP controllers, that lets the operator command combined thruster output with a single joystick if the DP system fails. It provides a simple, robust fallback layer between full automatic DP and individual manual thruster levers.

J

Joystick ModeDP
A semi-automatic DP operating mode in which the operator commands vessel movement with a joystick while the system coordinates the thrusters — often with automatic heading control engaged. Joystick mode is used for close manoeuvring, approach phases and DPO training in vessel handling.

L

Laser-Based Position ReferenceDP
A relative position reference that measures range and bearing to reflective targets mounted on a nearby structure — a platform, rig or another vessel — using a rotating laser. Because it positions the vessel relative to the asset it is working beside rather than in absolute coordinates, it is the reference of choice for close-proximity DP operations such as platform supply and walk-to-work.

M

MRU — Motion Reference UnitDP
An inertial sensor measuring the vessel's roll, pitch and heave. The DP system uses MRU data to correct position references for lever-arm and attitude effects — an antenna at the masthead swings metres as the ship rolls — making accurate motion data essential to stable position keeping.

O

Open Bus-Tie OperationDP
Running the power plant with bus-tie breakers open, splitting the switchboard into independent islands each feeding its own thrusters. Open bus provides robust physical fault separation — a fault on one island cannot black out the other — at the cost of higher fuel consumption and generator running hours compared with closed bus.

P

Position Reference DropoutDP
The temporary loss or rejection of a position reference signal — from satellite shading, acoustic interference, target obstruction or sensor fault. The DP system rides through short dropouts on its mathematical model, but sustained loss of references degrades position estimation and triggers escalation per the ASOG.
Position Reference System (PRS)DP
Any sensor system that tells the DP system where the vessel is: DGNSS, hydroacoustics, taut wire, laser and radar-based systems. DP class 2 and 3 operations require at least three references based on at least two different measurement principles, so that a common failure cannot silently corrupt the position solution.
Power Management System (PMS)DP
The control system that supervises the vessel's power plant — starting and stopping generators, balancing load, shedding non-essential consumers and preventing blackout. In DP vessels the PMS and DP system work in close coordination, and PMS failure modes are examined line by line in the FMEA.

R

RedundancyDP
The provision of independent, duplicated systems so that a single failure does not stop the vessel keeping position. True redundancy requires more than duplication: the redundant groups must be genuinely independent — separate power, cooling, control and (for DP 3) physical compartments — which is exactly what the FMEA sets out to prove.
Rig MoveDP
The planned relocation of a drilling rig between well locations, involving anchor handling vessels, tow masters and detailed procedures. For moored rigs it is a major marine operation with its own risk assessments and weather criteria; DP units instead transit under their own station-keeping capability.

S

SIMOPS — Simultaneous OperationsDP
Two or more independent activities conducted at the same time and place — for example diving while crane operations proceed, or a PSV alongside during helicopter operations. SIMOPS require a combined risk assessment and a clear hierarchy of control, because the safe limits for one activity can conflict with another's.
Single-Point FailureDP
Any single component, system or event whose failure alone would cause loss of position — the thing a redundant DP vessel must not have. Identifying and eliminating (or at least documenting) single-point failures is the central purpose of the FMEA and the redundancy design it verifies.
Station KeepingDP
Maintaining a vessel's position and heading within defined limits against wind, waves and current — by anchors and mooring, by dynamic positioning, or by a combination. Station-keeping integrity is the fundamental deliverable of every DP system, and the loss of it defines a DP incident.

T

TAM — Task Appropriate ModeDP
A vessel configuration selected for lower-consequence DP activities, where the full redundancy of CAMO is not required and some efficiency or operational flexibility is gained in exchange for accepted, documented risk. The choice between CAMO and TAM — and who may authorise it — is defined in the vessel's DP operations documentation.
Taut WireDP
A mechanical position reference that lowers a weight to the seabed and measures the angle and length of the constantly tensioned wire to compute relative position. Simple and independent of both satellites and acoustics, taut wire remains a trusted third-principle reference in shallow to medium water depths.
Thruster AllocationDP
The algorithm inside the DP controller that translates the required total force and turning moment into individual commands for each thruster — respecting thruster limits, forbidden zones and failure states while minimising power consumption. Allocation behaviour after a thruster failure is a key subject of FMEA analysis and trials.

U

UPS — Uninterruptible Power SupplyDP
Battery-backed power supplies that keep DP controllers, reference systems and critical instrumentation alive through transients and blackouts. DP rules require redundant, segregated UPS arrangements, and UPS battery condition and changeover behaviour are standard items in annual DP trials.

W

Watch CircleDP
The defined radius (or radii) around the vessel's setpoint used to grade position excursions — typically an inner alert circle and outer action circles tied to yellow and red DP alert states. Watch circle sizes are set per operation, based on the consequence of excursion and the physical constraints of the task.
Weather WindowOPERATIONS
A forecast period during which environmental conditions are expected to stay within the limits required for a planned marine operation, including contingency time to reach a safe state if the forecast deteriorates. Marine operations standards require defined operational criteria and forecast reliability margins before committing to weather-restricted work.
Wind Sensor (Anemometer)DP
Sensors measuring relative wind speed and direction, which the DP system uses for wind feed-forward — countering gusts with thrust before the vessel is pushed off position. Because a faulty wind sensor can command a real thrust response, wind sensor failure modes feature prominently in DP incident statistics and FMEA studies.
Worst-Case Failure Design Intent (WCFDI)DP
The single failure with the greatest impact on station-keeping capability that the vessel is designed to withstand — for example loss of one complete switchboard section with its thrusters. The WCFDI is defined during design, verified by the FMEA and trials, and underpins the consequence analysis running continuously during operations.
